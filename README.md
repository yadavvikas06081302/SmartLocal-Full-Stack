# SmartLocal — Full-Stack BTech Final Year Startup

**Developer: Vikas Yadav**

### Stack
HTML, CSS, JavaScript • Node.js • Express • MongoDB/Mongoose • JWT • bcrypt

### Features
- Customer registration/login
- Service-provider role
- Service marketplace and search
- Booking API
- Business dashboard
- AI-style service recommendation
- Responsive mobile UI
- MongoDB models
- JWT authentication

### Run
1. Install Node.js.
2. Open terminal in `backend`.
3. Run `npm install`.
4. Copy `.env.example` to `.env`.
5. Add your MongoDB Atlas URI (or use local MongoDB).
6. Run `npm start`.
7. Open `http://localhost:5000`.

Do not upload `.env`; upload `.env.example`.

### Startup business model
Provider subscription + booking commission + featured listings.

### Future scope
GPS matching, KYC verification, online payments, OTP, reviews, notifications and a trained ML recommendation model.
